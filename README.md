# Мої 3 найкращі міста світу

Лабораторна робота 1 з дисципліни «WEB-програмування».

Статичний багатосторінковий web-блог про три міста: Софія, Будапешт, Загреб.

## Структура
- `index.html` — головна сторінка
- `city-sofia.html`, `city-budapest.html`, `city-zagreb.html` — сторінки міст
- `form.html` — форма «Запропонувати місто»
- `images/` — зображення

## Технології
HTML5, Git, GitHub, GitHub Pages.
